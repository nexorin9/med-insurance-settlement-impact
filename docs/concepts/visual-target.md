# 视觉目标卡 · 医保结算清单取数影响分析

> 本环境**不具备图像生成能力**，因此本目录只提供结构化视觉目标卡，**不放任何伪造概念图**。
> 真实运行截图由收尾任务采集在 `docs/screenshots/`，两者在 README 的「概念 / 实测对照」小节并排呈现。

---

## 1. 三个状态

### 起始态 · 刚打开窗口

- 顶栏：左侧产品名 + 版本号；右侧三个大数字（已解析 / 已算出影响面 / 失败），数字用等宽字形右对齐；最右一个开关位显示「写类动作：关」。
- 主区：左侧取数视图树（按名称排列，选中项浅蓝底）；中间一张空表格，表头为「分区 / 字段 / 来源列 / 影响类型 / 置信度 / 口径 / 跳数 / 批次」；右侧详情栏收起。
- 底部状态条：左侧一行提示「尚未接入取数视图，请先配置院内只读库」；右侧一个「载入样例」链接。
- 画面观感：**冷灰底 + 深蓝主色 + 高密度表格**，像数据治理控制台，不像 demo 页。

### 首个可用瞬间 · 选完视图、登记完改动

- 窗口标题栏下方出现一条细的上下文条：`V_BILL_FEE` · 改动列 `FEE_AMT` · 改动类型「逻辑变更」· 摘要前 8 位。
- 中间表格被填满：必填字段排前，行高紧凑，超长理由文字截断 + 悬停出 tooltip；影响类型列用色块标签区分「实质受影响」（浅蓝）与「疑似波及」（浅琥珀）。
- 右侧详情抽屉滑出，标题是被点的那一行「医疗费用总额」，下面按跳数分层列出路径：`V_BILL_FEE.FEE_AMT` → `V_IP_REG.ADMIT_DATE`，每跳标注边类型与跳数。
- 顶部右侧出现一个「回写台账」按钮：当前**置灰**（未逐行确认），鼠标悬停提示「请先逐行确认判定」。

### 成形态 · 确认完并回写之后

- 中间表格每行左侧带一个确认勾选框；已确认行加浅绿左边线，未确认行保持默认色。
- 顶部三个大数字更新为本次统计（解析段数 / 影响面条数 / 待人工核对条数），变化时有一次 200ms 的数字滚动过渡。
- 详情抽屉底部有「回写台账」与「导出说明」两个按钮；回写成功后右下角浮出一条 toast「已回写 12 条变更记录（幂等键 …）」，3 秒后淡出。
- 托盘图标常驻；视图摘要变化时，托盘气泡提示「V_BILL_FEE 已变更，影响面已刷新」。
- 批次筛选器在表格上方，显示当前批次占位 `<EXAMPLE_BATCH>`，可一键切换。

## 3. 视觉语言

| 项 | 取值 | 说明 |
|----|------|------|
| 主色 | `#1F4E79` 深蓝 | 主按钮、选中项左边线、表头下边线 |
| 底色 | `#F4F6F9` 冷灰 | 窗口背景 |
| 卡片底 | `#FFFFFF` | 表格与详情栏面板 |
| 语义色 | 成功 `#2E7D32` / 警告 `#B26A00` / 危险 `#C62828` / 信息 `#1565C0` | 影响类型标签、确认状态、错误态 |
| 中性灰阶 | `#1F2933` / `#52606D` / `#9AA5B1` / `#E4E7EB` | 正文 / 辅助文字 / 占位 / 分隔线 |
| 间距栅格 | 8px（4 / 8 / 12 / 16 / 24 / 32） | 所有内边距与间隙取栅格值 |
| 圆角 | 卡片 4px / 浮层 6px / 模态 8px | 三级圆角 |
| 阴影 | 浮层 `0 2px 8px rgba(31,41,51,.12)` | 抽屉与 toast 专用 |
| 字体族 | `-apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif` | 中文系统字体栈，缺失时逐级回落 |
| 字体层级 | 页面标题 18px/600、区块标题 14px/600、正文 13px/400、辅助 12px/400 | ≥4 级 |
| 等宽字形 | 字段名、摘要、幂等键用 `SFMono-Regular, Consolas, "Liberation Mono", monospace` + `font-variant-numeric: tabular-nums` | 摘要与幂等键需要逐字符对齐 |
| 信息层级 | 顶栏三个大数字最显眼 → 中间表格 → 左侧树 → 右侧详情 | 表格是主战场，详情是补充 |
| 留白密度 | 高密度（行高 32px、单元格左右内边距 12px） | 医保办一屏要看几十行 |

## 4. 必须可达的约束

只允许画出现有依赖真能做出来的效果：

- **不做 WebGL / 3D 场景 / 视频动画**；过渡只用 CSS 式等价物（Swing `Timer` 驱动的 alpha 渐变，150–250ms）。
- **不用 emoji 当图标**：图标用内联 SVG 路径绘制（对角箭头＝影响流向、放大镜＝来源链、勾＝已确认、叹号＝待核对），不引入图标库依赖。
- **不做自定义字体渲染**：只用系统字体族 + 等宽回退，不内嵌字体文件。
- **不做实时折线/热力图**：图表若出现，只用 Swing 原生 `JTable` + 单元格色块表达数量级。
- **不引入动画库、不引入前端框架**：Swing 原生组件 + `BasicStroke`/`Graphics2D` 绘制。
- **所有界面元素必须在 1280 与 768 两档宽度下不横向溢出**：表格允许列内截断 + tooltip，不做横向滚动条以外的溢出。
